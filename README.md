## 安裝

**Git Bash**（VSCode 終端機下拉選 Git Bash）：

```bash
python -m venv .venv            # 若還沒建過
source .venv/Scripts/activate   # 啟用後提示字元會出現 (.venv)
pip install -r requirements.txt
```

**PowerShell**：

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

啟用後兩邊都直接打 `python`，所以下面的指令兩種殼共用。
不想啟用的話就每次指定直譯器（Bash 用 `/`，PowerShell 用 `.\`）：

```bash
.venv/Scripts/python.exe run_screener.py --all
```

## 換殼時容易踩的地方

* **Git Bash**：`which python` 會印出拼接壞掉的路徑，那是 Git Bash 對 Windows venv
  的顯示問題，實際解析是對的 —— 要確認裝到哪個直譯器，看 `sys.executable` 才準。
* **PowerShell**：路徑要用反斜線，`/d:/Desktop/...` 那種格式會被當成指令名稱，
  報 `CommandNotFoundException`；路徑含空格要加引號，加了引號就得用 `&` 開頭：
  `& "D:\Desktop\實習\side project\.venv\Scripts\python.exe" run_screener.py`
* **PowerShell 5.1 沒有 `&&`**，串接用 `;`，要「前一個成功才執行」用
  `指令A; if ($?) { 指令B }`。

## 日常操作

回補跑完之後，平常只需要這兩件事：

| 時機 | Git Bash | PowerShell / 排程 | 做什麼 |
|---|---|---|---|
| 交易日 15:30 後 | `./daily.sh` | `.\daily.bat` | ①行情、法人、外資持股、融資融券 ②集保 ③選股清單 ④個股頁報表 |
| 需要時 | `python run_daily.py --tdcc` | `.\weekly_tdcc.bat` | 只抓集保（手動補用） |

兩支腳本內容相同，都會自己 `cd` 到專案目錄並用 venv 的直譯器。
選股清單另存一份到 `logs/screener_latest.txt`，個股頁報表在 `report/latest.html`（用瀏覽器開）。

⚠ **Git Bash 要加 `./`**：打 `daily.bat` 或 `daily.sh` 會說找不到，
因為 bash 刻意不在目前目錄找可執行檔。`./daily.bat` 也能跑（會轉給 cmd）。

外資持股與融資融券的公布時間比行情晚，15:30 跑通常還抓不到當天的；
`run_daily.py` 每次執行會自動回頭補近 5 個交易日缺的，所以隔天就會齊。

## 為什麼集保放在每日排程

**集保資料本身是週頻的**（週五收盤資料、週六上架），每天跑不會拿到每日數據，
台灣也沒有公開的每日股權分散資料。每天跑的理由是**可靠性**：
那一週的快照會一直掛在 API 上直到下週六被換掉，所以每天跑等於把
「週六單次機會」變成「七天補救窗口」。已經在庫的那一週會直接跳過不重寫。

⚠ 漏掉整整一週就<b>再也拿不回來</b>，而大戶/散戶的「4 週變化」需要 5 週快照才算得出來。

## 支撐壓力

每檔入選股會列出三種東西：

* **水平價位**：近 120 日的成交量密集區（量最大的價位 = 最多人的成本）與前高前低，相距 1.5% 內合併
* **趨勢線**：連兩個以上波段低點（高點）往右延伸，之後沒被跌破（突破）、延伸到今天在現價 12% 內
* **警示**：上方 2% 內有壓力、今日跌破支撐

三年逐日重算檢定（19,717 筆，每個日期只用當時以前的資料）的結論：

| 情境                   | 20 日超額    | t 值  |
| 貼近壓力（下方 2% 內）  | **-0.52%**  | -2.60  |
| 剛跌破支撐             | **-0.74%**  | -2.42  |
| 剛突破壓力             | +0.55%      | +1.69  |
| 貼近支撐（上方 2% 內）  | -0.06%      | -0.27（樣本外翻轉） |

**壓力是真的，支撐不是。**「貼近支撐會反彈」不成立；真正有訊號的是「穿越」不是「靠近」。
所以警示只提醒不篩選。

**趨勢線沒有預測力。**同樣的逐日檢定，貼近／穿越趨勢線的八個情境全部不顯著（|t| < 1.6），
樣本外方向全部翻轉。留著只是方便對照圖形。合理的解釋：水平價位對應真實的成交密集區，
趨勢線是幾何作圖——斜線上一個月前的價位不是任何人的成本。

## 查任意個股（不只入選的

靜態報表只含入選股的資料。要查其他股票，開查詢伺服器：

```bash
python run_server.py          # 自動開瀏覽器到 http://localhost:8765
```
左上角搜尋框輸入代號或名稱，1,900 檔都能查；沒進母體的會標示「未進入今日母體」，
其餘資訊（六格圖、法人、籌碼、支撐壓力）跟入選股一樣。Ctrl-C 關閉。
只用 Python 內建模組，不用裝東西。

兩者共用同一份頁面，差別只在資料來源：
|      | 靜態報表 `report/latest.html` | 查詢伺服器 `run_server.py` |
| 能查 | 入選的個股                     | 任何一檔                   |
| 需要 | 雙擊開檔                       | 伺服器開著                 |
| 離線 | 可                            | 可（資料在本機）            |
| 適合 | 每天看清單、傳給別人            | 臨時想查某一檔             |

伺服器開著時 `daily.bat` 可能撞資料庫鎖（DuckDB 單寫入者）。
每個請求用完就關連線，撞到的機會很小，真撞到重跑一次即可。

## 使用順序

```bash

python run_backtest.py --csv trades.csv

# 邏輯一致性測試（screener 與 backtest 的條件必須相同）
python tests/test_consistency.py --dates 20

# 6. 選股
python run_screener.py                     # 最新交易日

python run_screener.py --mode reversal        # 只看打底反轉
```

## 歸因分析：問題出在「交集」

各條件單獨施用於同一母體的 20 日超額報酬：

| 條件                     | 訊號數 | 20日超額    | t 值   |
| 只有 Layer2 法人         | 19,786 | +0.05%     | +0.46  |
| 只有 MACD 金叉           | 8,381  | +0.28%     | — |
| 金叉 + DIF>0             | 5,761  | **+0.37%** | +1.66  |
| Layer2 + Layer3（現行）  | 1,224  | **-0.33%** | -0.68  |

每個條件單獨用都是微正，**交集卻是負的**。兩個可能的解釋：

1. 交集後樣本數掉到 1,224，20 日報酬標準差 20%，標準誤 0.58% ——
   -0.33% 完全落在雜訊範圍內，本來就測不出東西
2. 「投信連買 + 剛金叉 + 爆量」選到的是**已經漲一段**的股票，追高成分高於發掘成分

值得注意的是 **投信買超這一層幾乎沒有貢獻**（+0.05%、t=0.46），
而技術面的「金叉 + DIF>0」是唯一持續為正、且隨持有期遞增的組合（雖然仍不顯著）。

## 樣本外驗證：投信被推翻，外資站得住

把三年切成前後兩半各自獨立計算（持有 20 日）：

| 條件                 | 樣本內 2023-09~2025-02 | 樣本外 2025-03~2026-09 | 一致       |
| **外資嚴格**         | +0.31%　t=+2.60        | +0.81%　t=+4.84        | Y         |
| 金叉+DIF>0 + 外資    | +0.54%　t=+1.32        | +0.88%　t=+1.80        | Y         |
| 金叉+DIF>0 + 排名≤50 | +1.08%　t=+2.58        | +0.94%　t=+1.94        | Y         |
| **投信嚴格**         | **-0.65%　t=-5.54**    | **+0.76%　t=+3.98**    | N 方向翻轉 |
| 金叉+DIF>0 + 投信    | +0.34%　t=+0.77        | -0.43%　t=-0.75        | N 方向翻轉 |

投信那兩列是最好的教材：前後半段都「顯著」，方向卻相反。
**單一樣本的 t 值只說明「在這段資料裡穩定」，不說明「換一段還在不在」。**

## 市值控制：外資不是「大型股在漲」的代理變數

| 條件 | n | 對全母體 | 對同市值組 | 平均市值分位 |
